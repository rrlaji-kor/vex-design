# VEX IQ 로봇 설계

VEX IQ 2026-27 "Level Up" 대회용 로봇 구도를 잡는 스케치북 앱이에요. 두 사람이 같이 고치고, 고친 내용은 바로 서로의 화면에 반영돼요.

주소: https://rrlaji-kor.github.io/vex-design/

## 설치
- **안드로이드:** 크롬에서 주소를 열고 "앱 설치"(또는 메뉴 → 홈 화면에 추가)
- **맥북·윈도우:** 크롬이나 엣지 주소창의 설치 버튼 → 설치. 맥 사파리는 파일 → Dock에 추가
- 처음 한 번 구글 계정으로 로그인하면 돼요. 등록된 계정만 들어올 수 있어요.

## 저장
- 구상안과 수정 기록은 Firebase(Cloud Firestore)에 저장돼요.
- 읽고 쓸 수 있는 계정은 Firebase 콘솔의 Firestore 보안 규칙(이메일 목록)으로 정해요. 이메일이 공개되지 않게 규칙 파일은 이 저장소에 두지 않아요.

## 파일
| 파일 | 하는 일 |
|---|---|
| `index.html` | 앱 화면과 동작 |
| `config.js` | Firebase 연결 설정 (공개돼도 되는 값) |
| `manifest.webmanifest`, `icons/` | 설치용 이름과 아이콘 |
| `sw.js` | 인터넷이 없어도 앱이 열리게 하는 캐시 |
| `vendor/` | 3D 그림(three.js)과 Firebase 도구 |
| `seed.js` | Claude 앱에서 옮겨 온 첫 구상안·기록 (처음 한 번만 가져옴) |
