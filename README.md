# VEX IQ 로봇 설계

VEX IQ 2026-27 "Level Up" 대회용 로봇 구도를 잡는 스케치북 앱이에요. 옵션을 골라 로봇을 조합하고, 2D 도면과 3D로 확인하며 고쳐요.

주소: https://rrlaji-kor.github.io/vex-design/

## 설치
- **안드로이드:** 크롬에서 주소를 열고 메뉴(⋮) → 앱 설치(또는 홈 화면에 추가)
- **맥북·윈도우:** 크롬이나 엣지에서 앱 위 "앱 설치" 버튼 또는 주소창의 설치 아이콘. 맥 사파리는 파일 → Dock에 추가
- 한 번 설치하면 새 버전으로 저절로 바뀌어요. 인터넷이 없어도 열려요.

## 저장
- 구상안과 수정 기록은 **그 기기에만** 저장돼요. 계정도 서버도 쓰지 않아요.
- 앱을 지우거나 브라우저의 사이트 데이터를 지우면 같이 사라져요. 중요한 구상안은 "보내기"로 나에게 보내 두세요.
- 구상안 탭의 **보내기**로 링크를 만들어 카톡 등으로 보내면, 받은 사람이 눌러서 자기 앱에 추가해요.

## 파일
| 파일 | 하는 일 |
|---|---|
| `index.html` | 앱 화면과 동작 |
| `manifest.webmanifest`, `icons/` | 설치용 이름과 아이콘 |
| `sw.js` | 인터넷이 없어도 앱이 열리게 하는 캐시 |
| `vendor/` | 3D 그림 도구(three.js) |
| `seed.js` | Claude 앱에서 옮겨 온 첫 구상안·기록 (기기마다 처음 한 번만 가져옴) |
| `config.js` | 공유 저장(Firebase) 설정. 지금은 쓰지 않아서 비어 있어요 |
| `source/` | 앱 원본 코드. 고칠 때는 여기서 다시 만들어요 |
